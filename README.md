# Amazon-AGI-Ops-Delegation-Helper
Ops Portal Delegation Helper is a Tampermonkey userscript that streamlines DA delegation in the Amazon Annotation Ops Portal.

It adds:

A quick manager-selection dropdown
Buttons for common delegation durations, such as end of day, tomorrow, and end of week
Recent delegation history for quickly reusing previous manager and DA selections
Automatic deduplication of saved delegations
